# Home surface

Mode: Experience.

## Confirmed direction

The user explicitly requested The Legend of Zelda itself and modern React/Vercel tooling. The upgrade preserves a conventional portfolio workflow while replacing generic fantasy motifs with the Triforce, Master Sword, Hylian shield, Sheikah eye, heart HUD, and Hyrule terminology.

## First viewport

The welcome introduces Adonissimo; entering reveals Lorenz's identity and ordinary portfolio navigation. The "THE LEGEND OF ADONISSIMO" wordmark and original Master Sword landscape establish the theme. A clear primary link takes visitors to the project journal. The user-requested welcome waits for Enter on fresh home loads, offers immediate Skip/Escape, and has a static reduced-motion version. Section deep links bypass the welcome; route changes within the current document do not replay it unless requested. No gameplay is required.

## Visitor path

Home -> project journal -> real case-study route -> return to journal. Inventory identifies technologies used by this build rather than invented skill levels. About names Lorenz; contact links appear only when real values are supplied.

## Signature interaction

Day/night theme changes parchment and forest tokens while preserving legibility. Project status buttons update both visible entries and the live result announcement. The Triforce/wordmark welcome opens like a book cover into the landscape. A two-sided decorated leaf turns forward into projects and backward to the journal; section links retain native scrolling under the leaf. Journal filters turn the local page through native snapshots where supported. Gold sweeps, ripples and pressed states acknowledge clicks. Eighteen original procedural effects follow explicit activation, including paper, quest, menu, rupee, shrine, letter and rune cues. Independent effects mute/volume and randomized interaction effects live beside music in a scrollable dock with measured footer clearance. Replay welcome and manual motion controls are in the footer; system reduced motion always wins. The supplied Zelda's Lullaby MP3 starts from Enter/Play and continues while off screen, in background tabs, or across project pages; manual pause/mute remain authoritative. Optional media keys control the same root player. It never autoplays on load. Enter silently pauses music and turns effects off. No continuous visual animation.

Dependency downloads are denied by the environment (npm registry returns 403). Source parsing, data tests, SVG rendering, and static route checks are available. Next build, typecheck, ESLint, browser rendering, and accessibility-tree checks are not claimed until dependencies can be installed.
